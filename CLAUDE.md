# gitpancake.github.io

## Project Overview
Simple GitHub Pages site serving as the homepage for the gitpancake organization.

## Tech Stack
- **Platform**: GitHub Pages
- **Format**: Static HTML (overrides Jekyll)
- **Styling**: Inline CSS for simplicity

## Structure
- `index.html` - Main homepage with dark mode styling
- `_config.yml` - Jekyll configuration (minimal)
- `README.md` - Project documentation

## Development
This is a static site. Changes to `index.html` are immediately reflected on the live site at https://gitpancake.github.io after pushing to main branch.

## Design Philosophy
- Minimal and clean
- Dark mode by default
- Single purpose: simple greeting with link to main website
- No JavaScript or external dependencies
